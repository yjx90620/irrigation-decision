# 系统性升级方案：从"跑通"到"可发表"

本文档是原型阶段跑通之后的系统性改进设计。**核心结论：当前实验设置存在一个根本性问题，会削弱三篇论文的全部说服力，必须先修复，再谈创新。**

---

## 一、首先必须修复的根本问题（有实测证据）

### 1.1 问题：当前设置下"灌溉几乎不影响结果"

对已完成的 5400 次基线模拟做统计：

| 指标 | 数值 |
| --- | --- |
| 全部模拟产量中位数 | 14.30 t/ha |
| 25%—100% 分位区间 | 14.10 — 14.86 t/ha（**75%的模拟挤在 0.76 t/ha 的窄带里**） |

各站点雨养产量占充分灌溉的比例：

| 站点 | 雨养/充分灌溉 |
| --- | --- |
| 陕西关中 | **99.0%** |
| 河南北部 | 95.5% |
| 北京平原 | 93.9% |
| 河北中部 | 93.1% |
| 宁夏灌区 | 67.1% |

**5 个站点里有 4 个，不灌溉就能拿到 93—99% 的产量。** 这直接解释了原型阶段所有的"怪现象"：8 种基线策略的产量差异极小（14.23—14.43）、帕累托前沿薄得像条线、PPO 打不过简单阈值规则、迁移实验在 4 个站点"轻松成功"只在宁夏失败。**不是算法不行，是问题本身在这个设置下几乎不存在。**

### 1.2 根因一：生育期正好压在东亚季风上

| 站点 | 年降水 | 生育期(5/1—9/15)降水 | 占比 |
| --- | --- | --- | --- |
| 河北中部 | 541mm | 419mm | 77% |
| 河南北部 | 629mm | 464mm | 74% |
| 陕西关中 | 946mm | 599mm | 63% |
| 宁夏灌区 | 259mm | 190mm | 73% |

夏玉米需水约 400—500mm，而河北生育期降水就有 419mm。**这不是 bug，是真实的农学事实**：华北平原的夏玉米本来就基本雨养可行，该地区的地下水超采危机是**冬小麦**灌溉（10月—次年6月，完全避开季风）造成的。当前的作物—区域组合从设计上就选中了灌溉信号最弱的场景。

### 1.3 根因二：每年从田间持水量起算

`InitialWaterContent(value=["FC"])` 意味着每个生育季开始时土壤剖面是满的——在 2.3m 根系深度下相当于白送 150—200mm 有效水。真实农田不会这样。

### 1.4 修复方案：冬小麦—夏玉米轮作 + 土壤水分跨季接力（已实测验证）

实测（河北中部 2019—2020）：

| 情景 | 小麦产量 | 小麦灌溉 | 玉米产量 | 玉米灌溉 |
| --- | --- | --- | --- | --- |
| 全雨养 | 0.83 | 0 | **3.58** | 0 |
| 小麦充分灌溉/玉米雨养 | 0.83 | 302mm | **7.41** | 0 |
| 都充分灌溉 | 0.83 | 302mm | 7.43 | 291mm |

小麦收获时土壤被抽干到 0.124—0.148 m³/m³（壤土萎蔫点约0.15，即**剖面基本耗尽**）。**夏玉米产量从 3.58 到 7.41，动态范围超过 2 倍**——相比原设置的 13.48→14.48（7%），信号强度提升了一个数量级。

更重要的是，这创造了一个**真正有研究价值的问题**：年度配水额度在小麦和玉米之间怎么分配？给小麦多灌会抽干剖面损害后茬玉米，反之亦然。这是一个真实的跨季节序贯决策问题，比单季灌溉调度有意思得多，也更符合华北平原的实际水管理困境。

> ⚠️ **已知风险**：AquaCrop 自带的小麦参数不适配华北冬小麦。实测发现 `Wheat`（日历天数模式）4月29日就"成熟"了（华北实际6月上中旬收获），导致灌不灌产量都是 0.83；`WheatGDD`/`WheatLongGDD`（积温模式）则报错"积温不足以成熟"（2398 GDD 不够）。**冬小麦参数率定是这套方案的主要工作量和主要风险点**，需要查文献确定华北冬小麦的物候参数（GDD需求、Tbase、越冬春化处理）。如果率定不顺利，退路是只做夏玉米但改用真实初始墒情（下面 2.1），信号强度介于两者之间。

## 二、可增加的数据维度（已逐项验证可获取性）

## 三、三篇论文各自的创新点与对比实验设计

### 论文一：跨季节水量分配的多目标优化

**创新点**
1. **跨季节联合优化**——年度配水额度在冬小麦/夏玉米间的分配，考虑土壤水分跨季传递。文献中 AquaCrop 多目标优化绝大多数是单季的，跨季联合优化是明确的增量
2. **阶段边际水价值 (MWV)** 作为显式决策产品（方案 4.10 提出但一直没实现）——量化"每个生育阶段增加10mm灌溉换来多少产量"，输出可直接指导实践的排序
3. **多目标算法横向对比**——NSGA-II / NSGA-III / MOEA-D（pymoo 都支持），用 hypervolume、IGD+ 定量比较

**对比实验**
| 对比 | 内容 | 验证什么 |
| --- | --- | --- |
| 对比1 | 单季独立优化 vs 跨季联合优化 | **核心创新**：联合优化能否在同等总水量下拿到更高的系统总产量 |
| 对比2 | 初始墒情假设：固定FC vs ERA5-Land真实 vs 上季接力 | 量化"FC假设"造成的偏差有多大（也是对现有文献做法的一个批评） |
| 对比3 | NSGA-II vs NSGA-III vs MOEA/D | 算法选择对前沿质量的影响 |
| 对比4 | 阶段边际水价值的时空分异 | 哪个生育阶段的水最值钱，随站点/年型怎么变 |
| 对比5 | 历史气候 vs 2031—2050 HighResMIP delta-change 情景（audit-v3 4.4：非 SSP 下推；若论文需要 SSP，须新增真实 SSP 数据源） | 气候变化下最优灌溉策略怎么移动 |

### 论文二：残差式偏好条件化风险敏感强化学习

**创新点**
1. **残差策略（Residual RL）**——RL 不从零学，而是学"在阈值规则基础上该加/减多少"。这直接针对实测到的"PPO打不过简单规则"问题：起点就是规则基线的水平，只学增量，理论上不会更差。这是个有文献基础但在灌溉决策领域少见的做法
2. **风险敏感目标（CVaR）**——方案要求考虑风险，但目前只是个 -1 的惩罚项。改用分布式RL（sb3-contrib 的 QR-DQN）做真正的 CVaR 优化，直接优化"最差10%年份的表现"
3. **干旱场景优先采样**——论文二讨论里已提出的假说（均匀采样下极端干旱场景样本天然稀少），做成正式的课程学习/优先采样机制
4. **预报质量消融**——方案 5.13 设计了完美/气候统计/加噪三档预报，一直没实现

**对比实验**
| 对比 | 内容 | 验证什么 |
| --- | --- | --- |
| 对比1 | 从零PPO vs **残差PPO** vs 阈值规则 vs NSGA-II前沿 | **核心创新**：残差结构能否让RL真正超过规则 |
| 对比2 | 风险中性 vs **CVaR风险敏感** | 干旱年最差10%产量、低产概率 |
| 对比3 | 均匀采样 vs **干旱场景优先采样** | 难场景表现能否改善 |
| 对比4 | 预报质量：完美 / 气候统计 / 加噪预报 | 决策质量对预报精度的敏感性（实践意义强） |
| 对比5 | 四种偏好模式（稳产/节水/经济/平衡）的策略行为 | 偏好条件化是否真的有效 |
| 对比6 | 安全层 有 / 无 | 可实施性指标（非法动作率等） |

### 论文三：双因子迁移风险预测与负迁移门控

**创新点**
1. **双因子迁移风险预测器**——这是从我们自己的实验里长出来的原创发现：环境距离单独不足以预测迁移难度（实测陕西关中距离4.22但迁移差距仅0.06，宁夏距离5.10差距却达3.68）。提出用**环境距离 × 目标任务敏感度**（后者用论文一的帕累托前沿宽度量化）两因子预测迁移风险
2. **基于微调增益的负迁移门控**——不用静态距离阈值（会在陕西关中这类情况误判），改用"微调若干步后收益是否趋近于零"作为触发信号
3. **时间维度迁移**——历史气候训练→2050气候测试，不只做空间迁移。切题且新颖

**对比实验**
| 对比 | 内容 | 验证什么 |
| --- | --- | --- |
| 对比1 | 单因子(距离) vs **双因子**迁移风险预测 | **核心创新**：双因子能否更准地预测哪些迁移会失败 |
| 对比2 | 零样本 vs 微调 vs 目标域从头训练 | 补上缺失的第三对照组，量化迁移到底省了多少样本 |
| 对比3 | 均匀 vs 距离加权 vs **双因子加权** 实例采样 | 加权方式对迁移效果的影响 |
| 对比4 | 有 / 无**负迁移门控** | 门控能否避免"迁移了反而更差"的情况 |
| 对比5 | 空间迁移 vs **时间(气候)迁移** | 两类分布偏移的难度差异 |

## 四、系统性联动关系

这些升级不是各自独立的，改一处会传导到下游：

```
数据层升级（轮作 + 真实初始墒情 + CMIP6 + 土壤湿度）
        ↓ 信号强度提升一个数量级，且新增气候情景轴
论文一：跨季节优化 → 产出①帕累托策略库 ②阶段边际水价值 ③前沿宽度指标
        ↓ 前沿宽度 → 论文三的"目标任务敏感度"因子
        ↓ 帕累托前沿 → 论文二的性能上界参照
论文二：残差RL + CVaR + 干旱优先采样 → 产出训练好的策略网络
        ↓ 策略网络 → 论文三的迁移源
论文三：双因子迁移风险预测 + 负迁移门控 + 时间维度迁移
```

**关键联动**：论文一算出的"帕累托前沿宽度"直接成为论文三双因子预测器的第二个因子——这让三篇论文不只是并列关系，而是真正互相支撑，也是回应"每篇都要有创新"要求的一个自然结构。

## 五、工作量与风险评估

| 工作项 | 预估工作量 | 风险 |
| --- | --- | --- |
| 冬小麦参数率定 | 中—高 | **高**：AquaCrop 对越冬春化支持弱，可能需要较多文献调参 |
| 轮作串联框架（土壤水分接力） | 低 | 低（已验证可行） |
| ERA5-Land 土壤湿度接入 | 低 | 低（已验证API可用） |

| 论文二：残差RL + CVaR + 优先采样 | 中—高 | 中（CVaR/分布式RL需要装 sb3-contrib 并适配） |

**建议的推进顺序**：先做数据层修复（轮作+真实墒情），这是所有下游工作的前提；修复后先快速重跑一遍论文一的基线，确认信号强度确实上来了，再依次做三篇的创新点。
